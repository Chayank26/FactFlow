# Project working agreement

Complete work in the small phases agreed with the user. After EACH phase, before moving to the next, update all three learning logs:
- direction.md: what changed, why this phase came now, and verification.
- flow.md: cumulative user journey and how requests/data move at this point; distinguish working features from planned ones.
- tech.md: tools introduced or retained, why they fit this task, alternatives and trade-offs. Explicitly record when no new tool was needed.
Keep earlier phase entries. Keep the current-state summary accurate. Never mark a phase complete before its checkpoint is verified.
